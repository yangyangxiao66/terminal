已修复双终端拖拽导致内容错乱的问题。

根因是拖动时每一帧都会向两个 ConPTY 连续发送 resize，导致 Grok、Codex 等全屏 TUI 频繁重绘、错行叠字。

现在改为：

  • 拖动期间仅更新面板宽高比例
  • 松开鼠标后等待布局稳定
  • 对所有终端统一执行一次强制 fit + PTY resize

真实双终端拖拽验证通过：

  • 拖动过程中：0 次终端 resize
  • 松手后：两个终端各适配 1 次
  • 两个终端最终行列数与容器尺寸完全一致
  • npm run check 通过
